# SKYFY fork changes

Maintainer: Wildan Tirta Permana

This repository is a modified fork of Musify by Valeri Gokadze and contributors.
The original GPL-3.0-or-later license and copyright notices remain in force.

Changes made in this fork:
- Android app label changed to SKYFY.
- Android application ID changed to `com.wildan.skyfy`.
- Deep-link scheme changed from `musify://` to `skyfy://`.
- App version reset to 1.0.0 for the SKYFY fork.
- Custom SKYFY launcher icon and app artwork added.
- Home app bar branded as SKYFY with a short tagline.\n- Added a SKYFY home quick-access panel for Radio and Equalizer.
- About page redesigned with SKYFY identity and Wildan Tirta Permana maintainer credit.
- Default accent color adjusted to a violet/blue palette.
